# Фамильное древо

Простой сайт семейного древа: одна HTML-страница и один файл данных. Без сборки, без базы, без зависимостей.

Живой пример: https://family.victor-komlev.ru

## Как развернуть своё древо

1. Скопируйте папку `site/` (или сделайте форк репозитория).
2. Замените `site/people.json` своими данными (в репозитории — вымышленный пример), фото положите в `site/photos/`.
3. Проверьте локально:
   ```bash
   cd site && python -m http.server 8000
   ```
   и откройте http://localhost:8000
4. Выложите содержимое `site/` на любой статический хостинг: свой сервер с nginx, GitHub Pages, Netlify.

## Формат `people.json`

```json
{
  "meta": {"title": "Древо семьи", "root": "id-корня", "hideLiving": true},
  "captions": {"photos/файл.jpg": "Подпись к фото: кто, где, когда"},
  "people": [
    {
      "id": "ivanov-ivan",
      "surname": "Иванов", "name": "Иван", "patronymic": "Петрович",
      "maiden": "девичья фамилия (для женщин)",
      "sex": "m",
      "living": false,
      "birth": {"date": "1900-01-31", "place": "с. Такое-то"},
      "death": {"date": "~1970", "place": "", "cause": ""},
      "father": "id отца", "mother": "id матери",
      "spouses": [{"id": "id супруги", "date": "1925", "place": ""}],
      "notes": "свободный текст",
      "sources": ["метрическая книга …"],
      "photos": ["photos/файл.jpg"]
    }
  ]
}
```

- Даты: `ГГГГ-ММ-ДД`, или просто год, или `~1850` для примерной.
- Дети и братья/сёстры вычисляются сами по полям `father`/`mother`.
- `living: true` + `meta.hideLiving: true` — даты живых людей на сайте не показываются.

## Справочник

`python tools/build_reference.py [путь/к/people.json]` собирает `docs/reference.md` — читаемый список всех людей по фамилиям.

## Языки

Переключатель RU / IT вверху страницы (`?lang=it`). Перевод данных — файл `people.<язык>.json` рядом с `people.json`:
`{"meta": {"title": "…"}, "people": {"<id>": {"name": "…", "notes": "…"}}, "captions": {"photos/…": "…"}}` —
поля из него заменяют русские. Подписи интерфейса — объект `LANGS` в `index.html`.

## Импорт GEDCOM

GEDCOM (`.ged`) — общий формат программ для родословных (MyHeritage, Geni, FamilySearch, Gramps).

```bash
python tools/gedcom_import.py файл.ged site/people.json           # проверка: что добавится и что расходится
python tools/gedcom_import.py файл.ged site/people.json --apply   # записать
```

Люди сопоставляются по фамилии (или девичьей), имени, отчеству и году рождения. Новые добавляются,
у найденных дописываются только пустые поля; расхождения не перезаписываются, а выводятся в отчёт.
Новые люди без даты смерти, родившиеся после 1915 года, отмечаются живыми — их даты на сайте скрыты.

## Версии

Если данные лежат в git, `python tools/build_versions.py <репозиторий-данных> <каталог-сайта>` раскладывает
каждый коммит с `people.json` в `versions/<id>/` и пишет `versions/index.json`. На сайте появляется выбор версии
и плашка «старая версия». Чтобы скрыть версию, добавьте её короткий хеш в `versions-hidden.json` репозитория данных.
